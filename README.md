# VERDANT RELAY — GitHub Pages公開版

近未来の3D拠点育成ゲーム。ビームで残骸を解体し、合金・コアを取引して拠点を拡張します。

## GitHubの画面から公開する
1. GitHubで新しいリポジトリを作成します。推奨名は `verdant-relay`。Publicを選び、READMEを追加して作成します（ソースコードも一般公開されます）。
2. このZIPを展開し、中身の `index.html`、`style.css`、`game` フォルダー、`vendor` フォルダー、`README.md`、`.nojekyll` をリポジトリの直下へアップロードしてコミットします。ZIPそのものや、外側のフォルダーをアップロードしないでください。既存READMEはこのREADMEで置き換えて構いません。
3. リポジトリの Settings → Pages → Build and deployment で Source を `Deploy from a branch`、Branch を `main`、フォルダーを `/(root)` にして Save。
4. Pagesの設定画面に公開URLが表示され、デプロイが成功したら開きます。Asukiyoアカウントでリポジトリ名がverdant-relayなら、URLの形式は `https://asukiyo.github.io/verdant-relay/` です。これは予定URLで、現時点で公開済みとは限りません。

## 更新
変更したファイルを同じ場所へアップロードしてコミットすると再公開されます。npm installやビルドは不要です。

## 操作
スマホ：画面をドラッグして移動。PC：WASD・矢印キー、または地面をクリック。近くの敵・残骸へ自動照射。建設・強化マークでは1秒待機します。

## 敵機と攻撃
参考画像に近い錆びた装甲、露出した関節、苔、発光部を持つ4系統の機械です。敵機の表示は精細な透過画像を使う2.5D方式で、前後4方向と攻撃3ポーズを切り替えます。地形・移動・当たり判定は従来の3D空間で処理します。

- **スキッター**：4本の鎌脚。振り上げて前方を斬り、突進も行います。
- **ドリルビートル**：重装甲の四脚機。ドリルを高速回転させて前方を粉砕し、突進も行います。
- **シージウォーカー**：長い砲身を持つ二脚機。照準・砲身の持ち上げ・射撃反動があり、予告地点に砲弾が飛びます。
- **コアガーディアン**：大型の拳と胸部コア。両腕を上げて叩きつけ、周囲に衝撃波を発生させます。既存の大型敵・ボスに割り当てています。

固有攻撃には予備動作と硬直があり、地面の予告範囲から離れて回避できます。斬撃とドリルは前方、衝撃波は円形です。操作・セーブ形式は従来のままです。各機体は画像を共有し、ポーズの短いクロスフェードと影を合わせて最大3枚の描画で表示します。起動時にリポジトリ内の画像4枚（合計約9MB）を読み込みます。画像の読み込みに失敗した場合は通信エラーを表示し、既存セーブを書き換えません。自由な視点回転のある立体モデルではなく、画像の向きを切り替える方式です。

HTTP配信した `tests/enemies.html` で4種類の見た目・方向・攻撃ポーズを確認できます。`npm test` では各攻撃の判定・回避・硬直・突進の維持・セーブ互換性・画像枠・向きとポーズの切り替えを検証します。画像の生成方法とプロンプトは `assets/enemies/SOURCES.md` に記録しています。

## 保存データ
防衛・修理アップデートでは既存の保存キーとバージョンを維持します。旧セーブの施設は耐久最大で読み込み、既存のパルスタレットも維持します。

死亡時は手持ちの合金・コア・石材・金鉱石を各30%（端数切り捨て）落とします。お金と納品済み在庫は対象外です。落とした箱は時間で消えず、再読み込み後も残ります。箱のマークで1秒待つと回収できます。

敵は施設・防衛施設も攻撃します。耐久ゼロになると生産・射撃・運搬が停止します。「施設と部隊」から修理場所へ移動し、施設前のマークで1秒待つと合金で全回復します。修理費は不足耐久8につき合金1（切り上げ）です。

新しい防衛用地では単体ビーム砲・範囲ミサイル砲・減速電磁タワーの建設場所を選べます。敵は高速小型機、ダメージを軽減する四脚装甲機、予告位置を砲撃する遠距離砲撃機の3種です。建設・修理・回収は既存のドラッグ移動と待機操作で利用でき、スマホ専用の追加キー操作は不要です。

開発時の検証は `npm test`（戦闘・保存互換性）と `npm run check`（JavaScript構文検査）。依存パッケージのインストールやビルドは不要です。

進行状況はブラウザーのlocalStorageに保存されます。ChatGPT側の既存URLとは保存先が異なるため、以前の進行状況は自動移行されません。ブラウザーや端末が変わった場合も別セーブになります。

## 動作環境
WebGL対応のブラウザーが必要です。3D表示できない場合はハードウェアアクセラレーションの設定を確認してください。HTMLのダブルクリックではなく、HTTP配信で開いてください。
